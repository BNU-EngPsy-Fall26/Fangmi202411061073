# 信号检测论实验 · 保护区红外相机监测系统

> 作业一：构建一个信号检测论交互式实验网站
> 个人独立完成 | 使用 HTML + CSS + JavaScript 实现

一个基于**信号检测论（Signal Detection Theory, SDT）**的交互式实验网站。用户扮演自然保护区研究员，通过红外相机画面判断每一帧是否有目标珍稀动物经过，在游戏结束后获得完整的 SDT 指标分析报告。

---

## 🚀 如何运行

本项目为**纯前端项目**，不需要安装任何依赖，也不需要启动服务器。**直接双击 `index.html` 即可在浏览器中打开运行**。
